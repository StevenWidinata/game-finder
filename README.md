# Game Finder

A simple, phone-friendly directory of daily web games (Wordle, Krillion, Globle, Flagle and more).

- **Search** by name *or* by what the game is ("flag", "country", "math") — handy when you forget the name.
- **Filter** by category and by fun tier (S / A / B / C / D).
- **Rate** any game by tapping its tier badge.
- **Add, edit or remove** games with the buttons on the page.
- Everything you change is saved in your browser. Use **Export / Import** to copy it to another device.

## Add a game for everyone
Edit `games.js`, add an entry, commit and push (Vercel redeploys automatically if connected to this repo).

## Run locally
Open `index.html`, or run `npx serve` in this folder.
